# MEMORY — package

Память модуля. §1 — перезаписываемое текущее состояние (≤ 10 строк). §2 — карта, обновлять при новых пакетах/файлах. §3–4 — добавлять строки, неактуальное ~~зачёркивать~~. §5 — **только дописывать в конец** (`merge=union`). Решения для всей системы — ADR в `../../../docs/DECISIONS.md`.

## 1. Текущее состояние
- Реализованы приём, версии, шифрование, очередь и карточки; B1-1…B1-4: полная заявка, история, перепроверка и PDF-only с наличием ЭП.
- ZIP отклоняется до отдельного согласования; признаки ЭП определяются структурно, без проверки криптографии (ADR-026).
