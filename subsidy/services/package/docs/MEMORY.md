# MEMORY — package

Память модуля. §1 — перезаписываемое текущее состояние (≤ 10 строк). §2 — карта, обновлять при новых пакетах/файлах. §3–4 — добавлять строки, неактуальное ~~зачёркивать~~. §5 — **только дописывать в конец** (`merge=union`). Решения для всей системы — ADR в `../../../docs/DECISIONS.md`.

## 1. Текущее состояние
- Реализованы приём, версии, шифрование, очередь и карточки; B1-1, B1-2, B1-4: полная заявка, история, перепроверка, наличие ЭП в PDF. B1-3 (только PDF) отменено по кейсу.
- Приём всех форматов FR-03 и ZIP сохранён; признаки ЭП определяются структурно, без проверки криптографии (ADR-026). DOC/XLS — не поддержаны.
- PR #1: локально проверены компиляция, Checkstyle, ArchUnit, валидация и PDF-проверки; полный прогон PostgreSQL/Kafka требует Docker. OpenAPI экспортируется из контроллеров, типы клиента перегенерированы.
