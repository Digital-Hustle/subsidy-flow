# PRD — ocr

Продукт целиком — `../../../docs/PRD.md`, требования с ID — `../../../docs/REQUIREMENTS.md`. Здесь — только этот модуль.

## Обзор
Предобработка для docproc: PDF с текстовым слоем → текст и таблицы как есть (`pdfplumber`); скан/фото → рендер (`pypdfium2`), поворот, выравнивание, контраст, Tesseract `rus+eng`; метрики качества; рендер превью страниц для просмотрщика. Ничего не хранит.

## Проблемы
- Сканы под углом, с печатями и подписями поверх текста.
- Сметы и счета — таблицы, их структура важна для арифметики.
- Лицензии: PyMuPDF/poppler/ghostscript нельзя.

## Цели
1. Текст + слова с bbox + таблицы по каждой странице.
2. Метрики качества → причины UNREADABLE.
3. Страница ≤ 5 с на CPU.

## Пользователи
- docproc — `/v1/extract`; package — `/v1/render` (превью).

## Ключевые функции
- `POST /v1/extract` → страницы: текст, слова, таблицы, качество.
- `POST /v1/render?page=` → PNG.
- Предобработка OpenCV: EXIF, deskew, CLAHE, авто-поворот (OSD).
- Таблицы: `pdfplumber.extract_tables` для PDF-слоя; для сканов — группировка слов по строкам и колонкам по bbox.
