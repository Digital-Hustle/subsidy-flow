## 3. Решения уровня проекта
| Решение | ADR |
|---|---|
| Микросервисы как в «Проходной», очередь разбора в PostgreSQL | ADR-001, 002 |
| Тип по содержимому с сегментацией; модель читает — код проверяет | ADR-005, 006 |
| Деньги `BigDecimal`, протокол — неизменяемый снимок | ADR-007, 008 |

## 4. Риски
| Риск | Что делаем |
|---|---|
| Локальная модель медленная на CPU, пакет из 30 документов | сегментация по коротким выдержкам, кэш стадий, параллельность воркеров, `qwen3:4b` как запасная |
| Таблицы в сканах (сметы, счета) читаются плохо | pdfplumber для PDF-слоя, строки по bbox слов, vision-путь для таблиц |
| Чек-лист и формулы другие | `programs`/`checklists` — данные, правила — отдельные классы |
