# Виды документов пакета на субсидию (кейс 3, FR-30)

> Источник — текст кейса «Агентство инноваций» и открытый набор. Реестр — **данные**: `services/docproc/src/main/resources/doc-types/registry.json` (схема полей и подсказки для промпта), комплект — `programs.params` в rules (ADR-024). Поменять вид = правка реестра + прогон `eval/`, без правок кода.
> Признаки ниже — подсказки **для промпта модели**, а не правила классификации (rules.md §1.1, §1.3).

## Реестр видов
| code | Вид | Признаки (для промпта) | Поля (JSON Schema) |
|---|---|---|---|
| `APPLICATION` | Заявление (заявка) на предоставление субсидии | Заголовок «Заявление» или «Заявка на участие в отборе на предоставление субсидии», «прошу предоставить субсидию»; сведения о заявителе (наименование, ИНН, ОГРН/ОГРНИП), запрашиваемая сумма, бюджет проекта, подпись руководителя. | `orgName`, `inn`, `ogrn`, `projectName`, `requestedAmount`, `totalCost`, `ownFunds`, `date`, `signerName` |
| `PD_CONSENT` | Согласие на обработку персональных данных | Слова «Согласие на обработку персональных данных», ФИО субъекта, паспортные данные, перечень действий с данными, «152-ФЗ», подпись и дата. | `fullName`, `passport`, `date` |
| `CERTIFICATE` | Сертификат соответствия | Заголовок «Сертификат соответствия», регистрационный номер (например, ЕАЭС RU С-…), орган по сертификации, продукция, срок действия «с … по …». | `number`, `issuer`, `orgName`, `inn`, `issueDate`, `validUntil` |
| `PRESENTATION` | Презентация проекта | Слайды или страницы презентации: название проекта крупно, цели, задачи, описание, этапы, команда, бюджет, ожидаемые результаты. | `projectName`, `description`, `orgName`, `inn` |
| `COST_JUSTIFICATION` | Обоснование затрат (обоснование размера затрат, смета проекта) | Заголовок «Обоснование размера затрат», «Обоснование затрат», «Смета»; таблица статей расходов (наименование, количество, стоимость), итоговая сумма; может быть разбивка на собственные средства и средства субсидии. | `orgName`, `inn`, `projectName`, `totalCost`, `ownFunds`, `requestedAmount`, `items` |
| `BANK_STATEMENT` | Выписка (справка) из банка | Банковская выписка по счёту или справка банка об остатке денежных средств: наименование банка, БИК, номер счёта, владелец счёта, остаток на дату, подпись сотрудника банка, печать. | `orgName`, `inn`, `bankName`, `account`, `bik`, `balance`, `date` |
| `PROPERTY_DOC` | Документ на недвижимое имущество | Выписка из ЕГРН, свидетельство о праве собственности, договор аренды земельного участка или помещения: кадастровый номер вида 61:18:0600022:891, площадь, адрес (местоположение), назначение / вид разрешённого использования. | `cadastralNumber`, `area`, `purpose`, `address`, `rightHolder`, `date` |
| `GUARANTEE_LETTER` | Гарантийное письмо | Заголовок «Гарантийное письмо», «гарантирую(ем)», «обязуюсь», обязательства заявителя или гаранта (софинансирование, реализация проекта), подпись руководителя, дата. | `guarantorName`, `inn`, `amount`, `date`, `signerName` |
| `GIMS_DECLARATION` | Декларация (свидетельство) ГИМС о пляже | Документы Государственной инспекции по маломерным судам (ГИМС МЧС): декларация безопасности пляжа, акт технического освидетельствования пляжа, разрешение на пользование пляжем, срок действия. | `number`, `orgName`, `address`, `issueDate`, `validUntil` |
| `OTHER` | Документ вне перечня | Любой документ, не относящийся к видам выше. | `summary` |

Деньги и даты модель возвращает строками как в документе; нормализацию (BigDecimal scale 2, ISO-дата) и отметки `FORMAT_INVALID` делает docproc. ИНН и ОГРН проверяются по формату (10/12 и 13/15 цифр), контрольная сумма не проверяется: реквизиты в открытом наборе синтетические (ADR-025).

## Комплект по программам (`programs.params.required/conditional`)
| Программа | Обязательные | Условные |
|---|---|---|
| `INNOVATION` Инновационный проект | Заявление на субсидию, Согласие на обработку персональных данных, Презентация проекта, Обоснование затрат, Выписка из банка, Гарантийное письмо | Сертификат соответствия — если продукция проекта подлежит сертификации |
| `BEACH` Обустройство пляжа | Заявление на субсидию, Согласие на обработку персональных данных, Обоснование затрат, Выписка из банка, Документ на недвижимое имущество | Декларация ГИМС — если пляж используется для купания и подлежит освидетельствованию ГИМС |
| `MODERNIZATION` Модернизация производства | Заявление на субсидию, Согласие на обработку персональных данных, Обоснование затрат, Выписка из банка, Гарантийное письмо, Документ на недвижимое имущество | Сертификат соответствия — если продукция проекта подлежит сертификации |

Условный документ без отметки условия — предупреждение `CHK_CONDITIONAL` и строка «дошлите также» в запросе заявителю; если специалист отметил условие (флаг `condition` в параметрах пакета), документ становится обязательным.
