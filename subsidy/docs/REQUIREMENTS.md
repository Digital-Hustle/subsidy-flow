## I. Чек-лист «не снимут» (прогоняем перед защитой)
- [ ] Переименовать все файлы пакета в `1.pdf…N.pdf`, перемешать порядок, сменить расширения → типы те же
- [ ] Один PDF из трёх документов → три документа с правильными типами
- [ ] `grep` по `frontend/src`: нет вычисления сумм/дат/вердиктов; `curl` правил с подменой → сервер пересчитывает
- [ ] Изменить сумму в счёте правкой поля → правило арифметики пересчиталось на сервере, протокол обновился
- [ ] `curl` без токена на пакеты, файлы, протоколы → 401; чужой пакет → 404
- [ ] `docker compose restart docproc` посреди разбора → доделано; `restart postgres` → всё на месте
- [ ] `docker compose stop ollama` → `WAITING_MODEL`, не «проверено»; `start` → догнали
- [ ] Свой пакет, которого нет в открытом наборе (синтетика) → тип, поля и правила работают
- [ ] Чистая БД → очередь пустая, статистика нули

- [ ] `LLM_PROVIDER=ollama`, интернет выключен → разбор работает
- [ ] `gitleaks detect` по всей истории — чисто; в git нет документов организаций
