## Общие обязанности
- **Капитан (B1)**: оргвопросы, мерж-очередь, теги `subs-demo-N`, итоговый срез scope.
- **Хранитель качества (B2)**: после каждого изменения промптов/предобработки/порогов — прогон `eval/` и строка в отчёте.
- **Хранитель формул (B3)**: каждое правило — строка в RULES-CATALOG + тест с числами до кода.
- **«Злоумышленник»** — по очереди раз в 2 часа: переименование и перемешивание файлов, склейки, правка сумм, прямые ссылки без входа, рестарт посреди разбора, остановка модели (чек-лист I).
