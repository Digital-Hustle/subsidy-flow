## 1. Текущее состояние
- Актуальные зоны: `/apply` (заявитель), `/operator` (специалист), роли из штатной сессии.
- F1: общая форма заявки, создание и редактирование с ревизией, ошибки полей и проверка сохранённых значений.
- Форматы исходного кейса: PDF, DOC/DOCX, XLS/XLSX, JPG/JPEG/PNG; сервер проверяет содержимое.
- Документы: раздельные стороны, три состояния признаков, оригинал, повтор обработки, замена и дозагрузка.
- API через `shared/api`; SSE обновляет карточку, очередь опрашивается; превью и оригинал учитывают версию.
- Приёмочный отчёт и ограничения бэкенда: `docs/F1.md`; полный локальный CI ограничен окружением.
