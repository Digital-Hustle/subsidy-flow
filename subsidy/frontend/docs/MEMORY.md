- Готовы: вход (oidc-client-ts PKCE, токены в памяти, роли из claim `roles`), `shared/api` (fetch + problem+json, SSE по тикету, TanStack Query), очередь пакетов, создание пакета, загрузка файлов.

- Открытые вопросы: формат `bbox` и сегментов (X-02), формат протокола (X-03).
